# User instructions for Naukri applications

- Notice period: 15 days.
- For notice-period or similar “how soon can you join?” questions, answer: “15 days (approximately 2 weeks).”
- When asked for the last working day, calculate it as 15 days from the current date.
- If the calculated date falls on Saturday or Sunday, use the following Monday.
- Use this rule for future application runs and recruiter questions.
